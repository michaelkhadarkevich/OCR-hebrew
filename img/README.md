# Reference illustrations

`HTR-VT.png` illustrates the reference model architecture; `visual.png` contains non-Hebrew recognition examples. These are reference assets accompanying the original implementation, not measurements or handwriting samples from our Hebrew experiments. Cite the original HTR-VT work when using them.

Our measured baseline figures and their source CSV files are in [`docs/results/`](../docs/results/README.md). Real Hebrew samples are in the paired datasets under `data/`.
